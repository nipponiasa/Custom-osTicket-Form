# Σημειώσεις για developer

## Name & Email
Το όνομα name στη φόρμα μπορεί να είναι οτιδήποττε.
To email όμως πρέπει να αντιστοιχεί σε υπάρχοντα χρήστη.
Αν όχι, δημιουργείται νέος χρήστης. Αν ναι, τότε το όνομα αντικαθίσταται από το πραγματικό όνομα του user στην εφαρμογή (και αυτό που δηλώθηκε δεν παίζει κανένα ρόλο).


## Γλώσσα χρήστη

Η ενεργή γλώσσα αποθηκεύεται στο `$_SESSION['form_lang']` (π.χ. `'en'`, `'es'`), δηλαδή server-side (όχι στο sessionStοrage). 
Ορίζεται από τη `form_resolve_language()` στο `form/translations.php`, η οποία καλείται κατά το page load μέσω `form/form-bootstrap.php`.
Μπορεί να αλλάξει με GET param: `?lang=es`.
Σε endpoints (π.χ. `vin_lookup.php`) φορτώνεται με:
```php
form_load_language($_SESSION['form_lang'] ?? 'en');
```


## ΈΙχα πειράξει από το original *:

στο include\client\header.inc.php έχω προσθέσει τη γραμμή
<script src="<?php echo ROOT_PATH; ?>form/resources/form.js" defer></script>
ώστε να φορτώνεται το δικό μου αρχείο JavaScript σε κάθε σελίδα του!

Μετά όμως δημιούργησα τo custom plugin μου, και δεν χρειάζεται αυτή η αλλαγή.
