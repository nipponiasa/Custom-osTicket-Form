# Σημειώσεις για developer


## Δομή project

To project έχει όλα τα λειτουργικά αρχεία του μέσα στο φάκελο `/form`, με εξαίρεση το αρχείο `/new.php` το οποίο είναι το αρχείο εκκίνησης. Το path εκκίνησης είναι το `new.php` για τους users ή το `new.php?role=agent` για τους clients. Τα υπόλοιπα αρχεία είναι documentation κλπ. 

## JavaScript που χρησιμοποιείται από τη φόρμα

Η φόρμα χρησιμοποιεί το αρχείο `/form.js.` το οποίο χρησιμοποιείται, όχι μόνο από τη φόρμα, αλλά από το osTicket γενικότερα, διότι αλλάζει τα link στην αρχική σελίδα προς την custom φόρμα, προσθέτει link στο μενού κλπ. Αρχικά, το είχα συμπεριλάβει στο `include\client\header.inc.php` βάζοντας τη γραμμή, το οποίο δεν είναι καλή πρακτική. Μετά, έφτιαξα το custom plugin `Custom FrontEnd HTML` το οποιό προθέτει τον κώδικα `<script src="/form/resources/form.js" defer></script>` σε κάθε σελίδα του osTicket. Tα custom plugins μπαίνουν στο φάκελο `include/plugins`. Όμως, έτσι, επειδή προσθέτει το `form.js` σε κάθε σελίδα που φορτώντεται το osTicket bootstrap, εγώ δεν το φορτώνω στην custom φόρμα μου (φορτώνεται αυτόματα). 

## Name & Email

Το όνομα name στη φόρμα μπορεί να είναι οτιδήποττε.
To email όμως πρέπει να αντιστοιχεί σε υπάρχοντα χρήστη.
Αν όχι, δημιουργείται νέος χρήστης. Αν ναι, τότε το όνομα αντικαθίσταται από το πραγματικό όνομα του user στην εφαρμογή (και αυτό που δηλώθηκε δεν παίζει κανένα ρόλο).


## Γλώσσα χρήστη

Η ενεργή γλώσσα αποθηκεύεται στο `$_SESSION['form_lang']` (π.χ. `'en'`, `'es'`), δηλαδή server-side (όχι στο sessionStοrage). 
Ορίζεται από τη `form_resolve_language()` στο `form/translations.php`, η οποία καλείται κατά το page load μέσω `form/form-bootstrap.php`.
Μπορεί να αλλάξει με GET param: `?lang=es`.
Σε endpoints (π.χ. `vin_lookup.php`) φορτώνεται με:
```php
form_load_language($_SESSION['form_lang'] ?? 'en');
```
